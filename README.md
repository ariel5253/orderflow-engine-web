# orderflow-engine-web

[Español](README.es.md)

Angular order-summary screen. It shows lines, discounts with their origin, gifts with quantity, taxes and total.

## Status

Planned. It is built by task T-17 of the task plan (`spec/TASKS.md` in the `orderflow-engine-docs` repository), time-boxed to one hour. It runs alone with its own `Dockerfile` (nginx) and `compose.yaml`, and its configuration keys are listed in `.env.example`.
